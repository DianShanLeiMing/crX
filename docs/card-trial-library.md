# 卡牌补库

流程：**发现未知 → 确认卡名 → 本地试用 → 运行观察 → 人工确认正式补库**。

确认普通、觉醒或精英版本后点击“确认”，单份有效手牌样本即可使用，不要求其他对局的同名样本。
原始截图不修改，人工标注单独保存在 annotations.json。运行预测不会自动变成人工标注。

## 页面操作

| 选项 | 操作 | 含义 |
| --- | --- | --- |
| 待确认 | 确认 | 为选中样本指定准确卡名并自动启用 |
| 补库 | 确认正式补库 | 每卡汇总全部外观，只将符合建议条件且经人工核对的参考纳入内置库 |
| 全部 | 确认／更正卡名 | 选择具体样本纠正误标，系统撤销错误来源关联并检查冲突 |

所有列表支持按需选择、多选、全选、取消选择和清空选中，运行时禁用删除。
补库汇总中清空一种卡牌会删除该卡本地候选，包含正在使用的本地指纹；确认框列明范围。
已经正式纳入的内置参考保留。页面不再提供启用、撤销按钮；历史停用或补库失败的样本可在“全部”中重新确认卡名。
未知历史样本不会因后续识别成功而自动删除或自动确认，可自行确认或清空选中项。

## 同卡多份外观

同卡同版本最多启用8份不同指纹；普通、觉醒、精英分别管理。图像指纹距离不超过100的同卡样本合并来源，
外观差异较大的样本同时保留。识别时从原库与所有已启用指纹中选最近者，沿用1000距离阈值。
计算候选间距时先按卡名去重，同卡不同外观不会被当成两个竞争卡名。
不再计算综合评分或按最高分只选一个外观，原库已能识别也不会阻止人工补库。
达到8份上限时保留已确认标注并提示整理，不静默删除有效指纹。

## 运行观察与复核

补库表显示卡名、样本参考数、补库命中次数、正式补库、说明和缩略图。
多个样本来源合并为一份指纹时，数量和命中次数只计一次。
“样本参考数”指去重后参与识别的本地外观数量，不是人工确认的原始样本条数。
说明中的“本地试用中”表示已经参与识别，没有自动判定验证通过的步骤。已由内置库覆盖时显示“内置参考使用中”。

补库命中仅表示该本地指纹赢得匹配；由原库识别的次数不计入。未命中不等于无效，不会因此停用。
后台约每5秒保存运行统计，界面约每5秒刷新，结束对局也会刷写剩余统计。
距离过大或不同卡名候选过近时保留复核截图，其他有效指纹继续使用。

如果不同人工卡名对应近乎相同的指纹（距离不超过100），相关指纹停用并显示“需复核”，
说明列出冲突卡名。到“全部”中更正具体样本后重新检查；冲突解除可恢复，人工明确撤销项仍保持停用。
运行匹配次数、距离和间距用于观察，不宣称自动证明卡名正确。

## 正式补库

“正式补库”列仅显示“建议纳入”“已纳入”“暂不建议”。每份参考分别判断：人工确认有效、
运行命中至少100次、平均不同卡名候选间距至少100，且无已知卡名冲突、未被同卡内置参考覆盖。
一张卡的汇总命中次数不会让尚未命中的其他外观一起达标；详细数量和原因显示在下方详情中。
同卡有可纳入参考时显示“建议纳入”；否则有内置覆盖时显示“已纳入”，详情注明各份参考的状态。

停止任务后选中卡牌，点击“确认正式补库”，核对弹窗中的卡名、版本、截图、命中次数和匹配情况，
再点“确认加入内置库”。只有弹窗列出的参考会处理，确认前重新检查标注、运行记录和冲突。
命中次数是观察次数，不能视作正确率；此操作表示用户已核对实际识别结果。一次最多64份，近似参考去重。

源码运行时更新项目的 `crX/bot/card_reference_library.json`，无需手写Python；项目文件可随commit提交，
构建后随程序分发。内置库仅保存卡名与指纹，不包含截图、玩家信息或对局路径。
安装版或项目文件无写入权限时，生成本地 `card_samples/formal-library-export.json`，需合入项目后再发布；
导出不会被标为“已纳入”，也不会自动加入当前安装版的内置库。
运行端约每秒刷新内置补充库；文件损坏时保留原有识别库的正常使用。
清空本地样本、标注和本地指纹不会删除正式库；更正或移除正式参考需修改项目内置文件。

## 本地存储与兼容

使用原有 %APPDATA%/crX/card_samples 目录与原子JSON；无网络服务或新增依赖。
库格式更新为version 2，首次改写旧格式前保留 fingerprints-before-multi.json，运行计数和原始标注不清除。
历史trial、covered及active记录只要来源人工标注仍有效且无冲突，即按新规则启用；
历史disabled记录保持停用，可在“全部”中重新核对并确认卡名。每卡数量、全库大小、源文件与路径检查仍保留。

回归覆盖单份确认立即识别、多外观共同识别、版本分离、重复来源去重、8份上限、
人工更正与冲突解除、明确撤销、运行统计、选择性清空、损坏记录拒绝覆盖及界面操作。
