# 国服商店每日免费领取

2026-10-17，针对当前 MuMu 国服中文界面适配。入口为商店 → 礼包分类 → 超值推荐 → 每日精选左侧免费商品。
适用截图为 419×633 BGR、160 DPI，沿用设备启动时的显示配置。

## 流程

- 进入商店后明确选择礼包分类和“超值推荐”，验证选中状态，再搜索“每日精选”。
- 使用 1000 毫秒的慢速滑动，保留相邻画面的重叠范围；默认快速滑动的惯性可能跳过整个栏目。
  最多搜索 48 次，栏目出现过低时最多进行 7 次小幅调整，将商品状态移到固定底栏上方。
- 只在每日精选首个商品内识别实采中文“免费！”标签，并检查绿色亮度，排除弹窗背后被压暗的标签。
  当前仅处理该每日免费商品，不处理其他栏目或活动赠送。
- 点击商品后，必须同时识别商品弹窗的关闭按钮和明确的绿色“免费！”确认按钮，才确认领取。
  付费商品即使同样使用绿色按钮也不会被确认；无法确认免费时仅关闭已识别的商品弹窗。
- 领取后等待动画、必要时重新对齐栏目，只有检测到“已收集！”才增加领取次数并返回主界面。
  页面本来已收集时直接返回，不增加计数。
- 找不到栏目、标签不明确、确认超时、领取结果未确认或无法返回主界面均返回失败，沿用工作进程的有限恢复流程。
  只有成功检查才开始下一次一小时检查间隔，识别失败不记作“没有免费商品”。
