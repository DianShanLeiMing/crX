# 720×1280 原生匹配

当前设备输出、规则识别、点击、滑动、采样和录制统一使用 **720×1280、320 DPI、BGR**。
`screenshot()` 和备用截图通道直接返回设备像素，不再缩小为 360×640。
点击和录制中的出牌坐标均为原生坐标，不再乘二转换。

## 坐标与素材

- `bot/coords.py` 中的识别区域、点击位置、像素采样点，以及 `card_data.py` 中的出牌位置已迁移至 720p。
- 检测窗口的宽高按二倍迁移，像素数量阈值按四倍迁移；颜色容差和时间参数保持原义。
- `detection/reference_images` 中现有 313 张 PNG 已按宽高二倍、最近邻插值迁移。
  文件名中的 `360`、`native` 等标记记录原始素材来源，不代表它们是新采集的 720p 模板。
  匹配时直接在原生截图上搜索这些模板，不对截图缩放。
- 手牌图案为 **108×132**，四个左上角分别为 `(170,1072)`、`(304,1072)`、`(438,1072)`、`(572,1072)`。
  指纹统计各象限的全部原生像素，按颜色比例归一化为每象限 891 个统计单位，保留已有 4×16 指纹库及距离阈值。
  归一化只处理统计值，不缩小手牌图案。
- 桥区活动量按采样面积归一化，保持原有策略阈值单位。

## 历史数据与验证范围

旧 360×640 采集批次继续按元数据原尺寸读取和裁剪。旧 360×640、419×633 卡牌样本可查看和补库，
不会改写原始文件；实时战斗规则只接受 720×1280。

离线回归将历史 360p 截图合成放大为 720p，验证原生坐标识别、导航、出牌与像素保留。
这不能证明真实 720p 字体、抗锯齿和渲染细节与旧素材相同；真实设备全流程及模板效果仍需实机校准。
后续新增模板应优先从 720×1280、320 DPI 设备原图直接裁取。
